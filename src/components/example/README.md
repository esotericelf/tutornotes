# Example Module

This module provides interactive examples with key concepts and step-by-step solutions.

## Components

- **ExampleModule**: Main component that orchestrates the example display
- **KeyConceptHighlight**: Displays key concepts with KaTeX support
- **ExampleQuestions**: Shows example problems with step-by-step solutions
- **ExampleSidebar**: Provides navigation for topics and subtopics

## Features

- KaTeX rendering for mathematical expressions
- Interactive GeoGebra diagrams
- Step-by-step problem solutions
- Topic/tag navigation sidebar
